# Agent Workbench 界面设计

2026-10-26。调整现有 React/Ant Design/Vite 管理台的视觉和交互组织，并按用户后续反馈精简信息和尺寸；业务接口、认证、任务与数据版本规则保持沿用。

## 参考与取舍

- 用户提供的三张界面：采用深色侧栏、浅灰工作区、清晰的页面标题、紫色主操作和白色数据表格。品牌使用 Agent Workbench，导航展示已实现的知识库与检索能力。
- [Ant Design 列表页规范](https://ant.design/docs/spec/research-list/)：突出对象名称，保持筛选、列表、分页的顺序；次要信息渐进展开。页面标题、面包屑、数量和操作采用一致层级。
- [Ant Design 数据列表规范](https://ant.design/docs/spec/data-list/)：桌面用表格比较多个对象；完整内容通过抽屉展开；批量操作明确绑定已选项。
- [Refine 的 Ant Design List 实践](https://refine.dev/core/docs/ui-integrations/ant-design/components/basic-views/list/)：借鉴页面动作和列表工具栏的组织方式。继续使用现有 Ant Design 组件，没有新增 Refine、ProComponents 或其他框架依赖。

## 视觉基线

| 项目 | 实现 |
|---|---|
| 主色 | #6454e8；主操作、选中态、焦点 |
| 侧栏与顶栏 | #1b2030；桌面侧栏 208px，可收起为 64px；白色顶栏 56px |
| 工作区 | #f5f6fa；白色内容卡片、浅色分隔线 |
| 字体与间距 | 系统字体，正文 14px、表格正文 13px；页面标题 22px；控件 32px；6px 基础圆角、8px 卡片圆角 |
| 信息密度 | 页面留白 20/24px；表格纵向单元格间距 12px；次要元数据折叠或预览后查看 |
| 图标 | 保留导航、主要新增/上传及少量删除操作；编辑、刷新、URL 导入、视图切换采用文字，不给每个元素配图标 |
| 状态 | 成功、失败、处理中均有文字；颜色与小圆点辅助识别 |
| 主题入口 | web/src/theme.ts；布局及响应式规则在 web/src/styles.css |

## 页面和操作

| 页面 | 变化 |
|---|---|
| 登录与导航 | 统一品牌；账号仅保存在会话内存；桌面侧栏、手机抽屉导航；账号菜单退出；移除工作流/指南和底部标语 |
| 知识库 | 名称、模型、文档数、时间与操作分层；移除统计及引导卡；名称筛选并入列表顶部；Ctrl/Cmd+K 聚焦全局知识库搜索 |
| 文档列表 | 文件类型、来源、解析方式、状态、块数与大小；行内为管理/入库/更多，下载与删除收进菜单；筛选与列表标题合并 |
| 文档工作区 | 面包屑、文件名及状态；文档详情折叠；分块、配置、任务、刷新通过标签页切换 |
| 分块 | 桌面默认表格，手机默认卡片；用户可手动切换；预览抽屉分别展示正文、embeddingText 和来源；编辑保留版本校验 |
| 批量维护 | 空选择时不显示批量工具栏；切换视图保留已选项，翻页/筛选清空选择；全量操作位于“更多操作”，另行明确确认 |
| 检索 | 范围与问题优先呈现；高级参数折叠；保留真实策略、通道、分数类型、证据正文及授权来源下载 |

手机导航使用抽屉；表格横向滚动限制在内容容器内。键盘可见焦点、图标按钮的可访问名称和减少动画偏好均有对应处理。页面不增加未实现功能入口、虚构统计或用户管理。

上传与 URL 导入弹窗宽 560px，默认只展示原文件或 URL/文件名及自动入库开关。可选文档名和六项解析/分块参数放在“高级设置”，格式能力另行折叠；高级字段 forceRender 保持注册与校验，隐藏错误会自动展开。正文限制为视口内剩余高度并独立滚动，标题及底部按钮不随正文滚走。Chunk 编辑弹窗宽 640px、正文初始 8 行，保留错误提示、版本校验和原有预览/编辑层级规则。卡片来源摘要限制两行，预览中仍可查看完整元数据。
